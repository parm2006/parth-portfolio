# Parth Mohnot — Project Portfolio

A curated overview of software projects by Parth Mohnot, spanning full-stack applications, voice AI platforms, computer vision tools, desktop applications, and UCSB computer science coursework.

---

## Projects

| Name | What it is |
| :--- | :--- |
| [**Conduit**](https://github.com/parm2006/Conduit) | Windows wireless KVM for sharing mouse and keyboard input, rich clipboard formats, file pastes, and hardware-accelerated video across a local network. |
| [**OratorAi**](https://github.com/parm2006/Orator-AI) | Real-time voice conversation-practice platform from SB Hacks XII, using Deepgram, Gemini, ElevenLabs, and WebSockets. |
| [**StarWarsRag**](https://github.com/parm2006/StarWarsRAG) | Command-line question answering over Star Wars movie scripts using retrieval-augmented generation, Qdrant, FastEmbed, and Llama 3.3. |
| [**ScholarlySearchEngine**](https://github.com/parm2006/Scholarly-Search-Engine) | Academic search engine for discovering relevant research papers, with an emphasis on contributions from women and underrepresented scholars. |
| [**TerrariaPixelConverter**](https://github.com/parm2006/terraria-pixel-converter) | Converts pixel art into Terraria block and wall material lists. |
| [**AiScreenshotOrganizer**](https://github.com/parm2006/AI_Screenshot_Organizer) | Windows tool that uses AI vision to categorize screenshots into local folders. |
| [**ClashOfClanker**](https://github.com/parm2006/ClashofClanker) | Clash of Clans automation using AutoHotkey, Android Debug Bridge, OCR, and image matching for battles, resource collection, and upgrades. |
| [**UcsbCoursework**](https://github.com/parm2006/UCSB-coursework) | Portfolio index for UCSB coursework in object-oriented design, computer architecture, and operating systems. |
