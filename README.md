# Project Portfolio

A curated overview of my software projects, spanning full-stack applications, voice AI platforms, computer vision tools, desktop applications.

## Projects

| Name | What it is |
| :--- | :--- |
| [**NeuralNetworksRust**](https://github.com/parm2006/NeuralNetworksRust) | Pure-Rust deep-learning framework with reverse-mode autograd, multidimensional tensors and broadcasting, composable modules, convolution and pooling layers, activations, losses, optimizers, binary checkpoints, and numerical-gradient verification. |
| [**Conduit**](https://github.com/parm2006/Conduit) | Windows wireless KVM for sharing mouse and keyboard input, rich clipboard formats, file pastes, and hardware-accelerated video across a local network. |

| [**ScholarlySearchEngine**](https://github.com/parm2006/Scholarly-Search-Engine) | Academic search engine for discovering relevant research papers, with an emphasis on contributions from women and underrepresented scholars. |
| **Terraria Pixel Art Converter**<br>[https://terraria-pixel-art-converter.vercel.app/](https://terraria-pixel-art-converter.vercel.app/)<br>[GitHub](https://github.com/parm2006/terraria-pixel-converter) | Converts pixel art into Terraria block and wall material lists. |
| [**AiScreenshotOrganizer**](https://github.com/parm2006/AI_Screenshot_Organizer) | Windows tool that uses AI vision to categorize screenshots into local folders. |
