# Personal website

This folder contains the website for `parthmohnot.dev`. The repository-root `README.md` remains the GitHub project index.

The site is a dependency-free static HTML/CSS/JavaScript page. Open `index.html` locally to preview it. On Vercel, set the project's Root Directory to `pmdev`, Framework Preset to `Other`, and leave the build command empty.

Project names and links in the site refer to Parth's existing repositories. All ten project boxes appear in order under Projects; the project navigation links jump to each box and work without JavaScript. The interactive `parth@workspace` display cycles through eight authored SER-style examples, alternating four project responses with four general knowledge responses; it is not an actual SimpleEnglishRag terminal. Its four buttons skip the console queue to their project response without scrolling. Automatic rotation pauses briefly after a manual choice, then continues from that position; reduced-motion preferences disable automatic rotation.

The project panel uses the real Conduit and Freezlit app icons and a capture of IdeaQueue's public sign-in screen. Freezlit's SVG icon comes from `web/icon.svg` in its MIT-licensed source repository; its download link opens the Windows and Mac releases. The other seven thumbnails are generated concept illustrations tied to each project's subject, not screenshots of those apps. The illustrations were generated with the built-in image generation tool and optimized as WebP for the site.
