# Personal website

This folder contains the website for `parthmohnot.dev`. The repository-root `README.md` remains the GitHub project index.

The site is a dependency-free static HTML/CSS/JavaScript page. Open `index.html` locally to preview it. On Vercel, set the project's Root Directory to `pmdev`, Framework Preset to `Other`, and leave the build command empty.

Project names and links in the site refer to Parth's existing repositories. The interactive `parth@workspace` display cycles through project-specific and general SER-style questions as a portfolio easter egg; it is not an actual SimpleEnglishRag terminal. Its four buttons select a project immediately, while the automatic question rotation pauses briefly after a manual choice.

The project panel uses the real Conduit app icon and a capture of IdeaQueue's public sign-in screen. The other seven thumbnails are generated concept illustrations tied to each project's subject, not screenshots of those apps. The illustrations were generated with the built-in image generation tool and optimized as WebP for the site.
